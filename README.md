# Rom Explorer

Bonjour

Je travaille pour France Travail. Je veux pouvoir trouver une vidéo métier sur YouTube à l’aide d’un formulaire sur une landing page et en récupérer des éléments significatifs personnalisés.

Pour trouver la vidéo, l’utilisateur devra noter le code ROM du métier rattaché dans un cadre.

Ce code ROM générera le nom ROM du métier dans le cadre suivant.

C’est à l’aide de ce nom de métier ROM que la recherche s’effectuera dans YouTube.

Pour lancer la recherche, il y aura un CTA : « Rechercher »

Une fois la vidéo trouvée, l’URL de partage sera copiée dans un cadre appelé : « Lien long »

L’URL affichée lors de la lecture comprenant watch sera copiée dans un autre cadre appelé : « Lien watch »

La vidéo doit avoir une durée de 4 minutes maximum

Il faut pouvoir lire la vidéo dans l’outil

Ensuite, je veux récupérer un résumé de la transcription par YouTube de la vidéo et la copier dans un espace sur la page web.

Tous ces éléments seront conservés dans une table Supabase

La landing page doit correspondre à la charte graphique de France Travail
